# Praktyka
Praktykа:
Na pierwszych zajęciach poznaliśmy prowadzącego oraz zasady BHP i organizacji pracy. Omówiliśmy projekt, jego wymagania i sposób oceniania.
Git i GitHub
Założyliśmy konta na GitHubie i utworzyliśmy lokalne repozytorium. Ćwiczyliśmy podstawowe operacje:
commit — zapisywanie zmian w historii projektu;
push — wysyłanie lokalnych zmian do GitHuba;
pull — pobieranie zmian z repozytorium zdalnego;
pull request — zgłaszanie zmian do przeglądu i scalenia.
Ćwiczyliśmy również rozwiązywanie konfliktów podczas scalania zmian. Zabezpieczyliśmy gałąź main przed bezpośrednim wprowadzaniem zmian.
Automatyczne sprawdzanie kodu
Poznaliśmy podstawy ciągłej integracji (CI). Dodaliśmy workflow GitHub Actions, który automatycznie sprawdza kod projektu.
